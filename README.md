# NumPy Learning Notebooks

A small collection of dated Jupyter notebooks for learning and practicing NumPy in Python.

## Requirements

- Python 3
- Jupyter Notebook
- NumPy

## Run the notebooks

1. Clone or download this repository.
2. Open a terminal in the repository folder.
3. Install the notebook dependencies:

   ```bash
   python -m pip install numpy notebook
   ```

4. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open either notebook from the Jupyter file browser.
